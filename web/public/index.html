Rhino

Antivirus de bajo consumo para Windows. Sin telemetría.

Base de datos de firmas

Reglas YARA-X precompiladas y hashes conocido-malo. El paquete va firmado (Ed25519) y Rhino comprueba la firma y el SHA-256 de cada archivo antes de usarlo.

Consultando el canal estable…

Canal estable. Para probar otro canal basta con apuntar la aplicación a su carpeta: un canal es un directorio.

Descargas

Windows 32 bits Windows 64 bits

Windows 10 o superior. La compilación de 32 bits es la que corre también en Windows de 64 bits.

Probar en local

Con este sitio levantado, cualquier Rhino descarga de él en vez de hacerlo de internet: 

RHINO_DB_URL=http://localhost:27182/db/stable cargo run -p rhino-app

O instalar el paquete sin pasar por la aplicación: 

cargo run -p rhino-db -- update http://localhost:27182/db/stable ~/.local/share/rhino/rhino-db

Nada sale del equipo. Rhino no envía rutas, nombres de archivo, contenido ni telemetría. Lo único que cruza la red es la descarga de este paquete.
